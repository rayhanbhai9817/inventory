# Frontend — Inventory Management SaaS

Next.js (App Router) + TypeScript + Tailwind CSS frontend for the Inventory
Management SaaS platform. See the [repository root README](../README.md)
for the full project overview and architecture.

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Requires the backend
API running (see `../backend/README.md`) and `NEXT_PUBLIC_API_URL` in
`.env.local` pointing at it.

## Build

```bash
npm run build
npm run start
```
